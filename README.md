# Демонстрационный проект по тестированию REST API
![This is an image](images/dm_api_account.png)

### Пример того, как может выглядеть структура проекта по автоматизированному тестированию REST API на языке Python

## Стек технологий:
- python 3.11
- pytest - как база для фреймворка
- allure - report для отчетов по результатам тестирования
- swagger-coverage - для анализа тестового покрытия
- requests - для REST запросов
- pydantic - для валидации запросов и ответов через модели
- pyhamcrest - как один из способов проверки полей ответа
- pytest-telegram-notifier - для нотификаций в TG по результатам тестирования
- vyper-config - как пример конфигурации проекта
- и многое другое...

### Написан Dockerfile для запуска тестов в контейнере, а также реализован удаленный запуск тестов на GitHub Actions.
